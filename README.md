# BeautyChem AI

**Косметикалық өнімдерді камера арқылы тану және құрамындағы химиялық заттарды талдау (PWA)**

Ғылыми жоба: «Косметикалық өнімдер құрамындағы химиялық қоспалардың адам терісіне әсерін зерттеу»
Авторы: Кенесова Амина, 9-сынып оқушысы. Жетекшісі: Бозақова Рауза.

---

## 1. Қосымша не істейді

1. Камерамен өнімді суретке түсіреді немесе галереядан сурет жүктейді (JPG, JPEG, PNG, WEBP).
2. **Gemini Vision** бренд, өнім атауы, түрі, көлемі, SPF және танылу сенімділігін анықтайды. Белгісіз өнім ойдан шығарылмайды: сенімділік төмен болса, ықтимал нұсқалар ұсынылады және қолданушы түзетеді.
3. Нақты INCI құрамы мына ретпен ізделеді:
   1. жергілікті өнімдер базасы (SQLite, `products` кестесі);
   2. өндірушінің ресми сайты және сенімді каталогтар (Gemini + Google Search grounding; нақты веб-дереккөзсіз табылған тізім **қабылданбайды**);
   3. құрам табылмаса, қолданушыдан қаптаманың артқы жағын түсіру сұралады, **OCR** мәтінді оқиды, қолданушы тексеріп түзетеді; қолмен енгізуге де болады.
4. Әр ингредиент **жеке химиялық базадан** (14 бастапқы зат + қолданушы қосқандар) ізделеді: формуласы, қасиеттері, қызметі, терідегі әсері, дереккөздері. Базада жоқ зат «Химиялық базаға енгізілмеген» деп белгіленеді және «Базаға қосу» батырмасы шығады.
5. Қазақ тілінде ғылыми қорытынды беріледі (тек химиялық базадағы деректер негізінде).
6. Нәтиже тарихқа сақталады, 2–3 өнімді салыстыруға болады. 3D молекулалар PubChem-тен жүктеліп, canvas арқылы көрсетіледі.

**Қағидалар:** INCI құрамы ешқашан ойдан шығарылмайды; AI кілті жоқ болса, жалған жауап көрсетілмейді, нақты қате хабары шығады.

## 2. Жоба құрылымы

```
BeautyChem-AI/
  frontend/            React + TypeScript + Vite + Tailwind CSS
  backend/             Node.js + Express (API, Gemini, дерекқор)
    src/  test/
  database/
    schema.sql                 SQLite схемасы
    ingredients.seed.json      14 бастапқы ингредиент
    beautychem.db              (бірінші іске қосқанда өзі жасалады)
  public/
    icons/                     PWA белгішелері
    manifest.json              Web App Manifest
    service-worker.js          Service Worker
    offline.html               Офлайн бет
  .env.example
  package.json                 (workspaces: frontend + backend)
  README.md
```

**Қажетті тәуелділіктер** (`npm install` өзі орнатады):
- Backend: `express`, `multer`, `express-rate-limit`, `dotenv`. SQLite үшін Node.js-тің кірістірілген `node:sqlite` модулі қолданылады (қосымша орнату қажет емес).
- Frontend: `react`, `react-dom`, `react-router-dom`, `vite`, `@vitejs/plugin-react`, `typescript`, `tailwindcss`, `postcss`, `autoprefixer`.
- Түбір: `concurrently` (backend пен frontend-ті бір командамен қосу үшін).

## 3. Іске қосу: қадамдық нұсқаулық

### 1) Node.js орнату
[nodejs.org](https://nodejs.org) сайтынан **Node.js 22.13 немесе одан жаңа (LTS 22 немесе 24)** нұсқасын жүктеп орнатыңыз. Тексеру:
```
node -v     # v22.13.0 немесе жоғары болуы керек
npm -v
```

### 2) ZIP архивті ашу
`BeautyChem-AI.zip` файлын тінтуірдің оң жағымен басып «Extract All / Всё извлечь» таңдаңыз (мысалы, `Документы` папкасына).

### 3) VS Code арқылы жобаны ашу
VS Code → **File → Open Folder** → `BeautyChem-AI` папкасын таңдаңыз. Терминал: **Terminal → New Terminal** (барлық команда осы папкада орындалады).

### 4) `npm install` орындау
```
npm install
```
Бұл бір команда backend пен frontend тәуелділіктерін бірге орнатады (интернет қажет, 1–3 минут).

### 5) `.env` файлын жасау және Gemini API кілтін енгізу
1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) сайтында Google аккаунтымен кіріп, **Create API key** батырмасын басып, кілтті көшіріп алыңыз.
2. `.env.example` файлын көшіріп, атын `.env` деп өзгертіңіз:
   - Windows (PowerShell): `Copy-Item .env.example .env`
   - macOS / Linux: `cp .env.example .env`
3. `.env` файлын VS Code-та ашып, кілтті **осы жолға** қойыңыз:
   ```
   GEMINI_API_KEY=сіздің_кілтіңіз
   ```
Кілт тек серверде сақталады және браузерге ешқашан жіберілмейді. `.env` файлын ешкімге жібермеңіз. Кілтсіз химиялық база, іздеу, қолмен енгізілген құрамды талдау, тарих, салыстыру жұмыс істейді, ал AI тану, OCR, интернеттен іздеу және қазақша қорытынды жұмыс істемейді (қосымша бұл туралы нақты ескертеді).

### 6) Backend іске қосу және 7) Frontend іске қосу
Дамыту режимінде екеуі бірге бір командамен қосылады:
```
npm run dev
```
Терминалда `backend` (порт 3001) және `frontend` (порт 5173) жолдары шығады. Қолданбаны ашыңыз: **http://localhost:5173**

Бөлек іске қосқыңыз келсе (екі терминал):
```
npm run dev -w backend
npm run dev -w frontend
```

### 8) Өндіріс режимі (PWA толық жұмыс істейтін режим)
Service Worker және орнату (install) тек құрастырылған нұсқада жұмыс істейді:
```
npm run build
npm start
```
Қолданба: **http://localhost:3001** (frontend пен API бір серверде).

### 9) Жергілікті тестілеу
```
npm test
```
Backend тесттері (14 тест): химиялық база, формулалар мен молекулалық массалар, INCI бөлу, сәйкестендіру, құрам іздеу ережелері, тарих. Тесттер Gemini орнына уақытша жергілікті сынақ серверін қолданады, сондықтан API кілтін жұмсамайды.

Жеке тексеру тізімі (құрылғыда қолмен):

| Функция | Қалай тексеру |
|---|---|
| **Сурет жүктеу** | «Галереядан жүктеу» → JPG/PNG/WEBP таңда → алдын ала көру, «Ауыстыру», «Суретті жою» жұмыс істейді. PDF/GIF таңдасаң қате хабары шығады. |
| **Камера** | HTTPS-пен (немесе `localhost`) ашып, «Камерамен түсіру» → камераға рұқсат бер → артқы камера ашылады → түсіру → «Қайта түсіру». |
| **AI тану** | `.env`-де кілт болғанда, өнім суретін «Талдауды бастау» → бренд/атау/түр/сенімділік көрінеді. Кілті жоқ болса, нақты ескерту шығады. |
| **OCR** | Құрам табылмаған кезде «Артқы жағын түсіру» немесе «Суреттен оқу» → INCI мәтіні өріске түседі, түзетуге болады. |
| **Химиялық база** | «База» бөлімі: іздеу (`niacin`, `C3H8O3`), сүзгі, карточка, 3D молекула (интернет қажет, кейін кэште сақталады), «Қосу». |
| **Сәйкестендіру** | Құрам өрісіне `Aqua, Glycerin, Nicotinamide, Parfum` енгіз → 2 зат табылады, `Aqua` мен `Parfum` «Химиялық базаға енгізілмеген». |
| **PWA орнатылуы** | Төмендегі 11–12 қадамдар. Chrome DevTools → Application → Manifest / Service Workers. |

### 10) HTTPS арқылы жариялау
Телефонда **камера тек HTTPS-пен** жұмыс істейді (`localhost` ерекшелік). Үш жол:

**А) Жылдам сынақ (компьютердегі қосымшаны телефонға HTTPS-пен ашу).** `npm run build && npm start` іске қосып тұрғанда, екінші терминалда Cloudflare Tunnel:
```
cloudflared tunnel --url http://localhost:3001
```
(`cloudflared` орнату: [developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)). Команда `https://….trycloudflare.com` мекенжайын береді, оны телефонда ашыңыз. Баламасы: `ngrok http 3001`.

**Б) Тұрақты жариялау (мысалы Render.com).** Жобаны GitHub-қа жүктеңіз (`.env` жүктелмейді, ол `.gitignore`-да), Render-де **New → Web Service** таңдап:
- Build Command: `npm install && npm run build`
- Start Command: `npm start`
- Environment: `GEMINI_API_KEY` = кілтіңіз, `NODE_VERSION` = `22`

Render HTTPS-ты автоматты береді. Ескерту: тегін тарифте файл жүйесі уақытша, сондықтан SQLite деректері (тарих, қосылған ингредиенттер) қайта жариялағанда жоғалуы мүмкін; тұрақты сақтау үшін Render **Disk** қосыңыз және `DATABASE_PATH` оның жолына бағыттаңыз. Railway, Fly.io, VPS (Nginx + Let's Encrypt) да жарайды: бастысы Node 22.13+ және HTTPS.

**В) Жергілікті HTTPS (mkcert).** `mkcert` арқылы сертификат жасап, `.env`-де `SSL_KEY_PATH` және `SSL_CERT_PATH` көрсетсеңіз, сервер `https://` режимінде қосылады.

### 11) Android телефонына орнату
1. Қосымшаны **Chrome**-да HTTPS мекенжайымен ашыңыз.
2. Басты бетте «Қосымшаны телефонға орнатыңыз» жолағы шығады → **Орнату**. Немесе Chrome мәзірі (⋮) → **Install app / Қосымшаны орнату**.
3. Белгіше басты экранда пайда болады, ол толық экранда (адрес жолынсыз) ашылады.

### 12) iPhone телефонына орнату
1. Қосымшаны **Safari**-де HTTPS мекенжайымен ашыңыз (iPhone-да тек Safari орната алады).
2. **Бөлісу** (шаршыдан жоғары көрсеткі) → төмен жылжып **«Басты экранға қосу»** → **Қосу**.
3. Белгіше басты экранда пайда болады. Камераға алғаш рет рұқсат сұралады: **Рұқсат ету**.

## 5. Химиялық база туралы

Бастапқы базада: Glycerin, Niacinamide, Dimethicone, Titanium Dioxide, Zinc Oxide, Avobenzone, Octinoxate, Oxybenzone, Tocopherol, Salicylic Acid, Citric Acid, Panthenol, Ethanol, Talc.

- Барлық формулалар мен молекулалық массалар автоматты тестпен тексерілген (`npm test`): формуладан есептелген масса базадағы мәнмен сәйкес келеді (диметикон үшін қайталанатын буын C₂H₆OSi, өйткені полимер).
- **INCI атаулары:** косметика құрамында Avobenzone — *Butyl Methoxydibenzoylmethane*, Octinoxate — *Ethylhexyl Methoxycinnamate*, Oxybenzone — *Benzophenone-3*, Ethanol — *Alcohol* деп жазылады. Сондықтан бұл заттар INCI атауымен сақталған, ал халықаралық атаулары синоним ретінде қосылған (екеуі де табылады).
- Сәйкестендіру тек **нақты атау немесе синоним** бойынша жасалады (ұқсас атауларды болжамайды: мысалы, *Tocopheryl Acetate* ≠ *Tocopherol*).
- Дереккөздер ретінде PubChem, ЕО CosIng, CIR, SCCS және ЕО Регламенті 1223/2009 бетіне сілтемелер берілген (іздеу/негізгі беттер). Сипаттамалар (механизм, пайдасы, тәуекелі) жалпы ғылыми мәліметтерге негізделген қысқаша мазмұн. **Жобаны қорғау алдында жетекшімен бірге нақты дереккөздер бойынша тексеріп, қажет болса түзетіңіз** (карточкаларды базадан өңдеу үшін `database/ingredients.seed.json` файлын өзгертуге болады).
- Жаңа зат қосу: «База» → «Қосу». Қосылған зат «пайдаланушы қосқан» деп белгіленеді.

## 6. Белгілі шектеулер

- AI мен интернеттегі іздеу қате жіберуі мүмкін, сондықтан құрам әрқашан қолданушының тексеруіне ұсынылады және дереккөзі көрсетіледі.
- Өнім формуласы елге және шығарылған жылға байланысты өзгереді; «жергілікті база» жазбаларына нарық пен жыл қосуға болады.
- Ингредиенттердің нақты концентрациясы құрамнан белгісіз (INCI тізімі 1%-дан жоғары заттар үшін кему ретімен жазылады).
- Бейорганикалық кристалдар мен полимерлер (TiO₂, ZnO, тальк, диметикон) үшін дискретті 3D молекула жоқ, қосымша бұл туралы хабарлайды.
- iPhone үшін арнайы splash-суреттер (apple-touch-startup-image) жасалмаған: қосымша ішіндегі splash экраны көрсетіледі.
- Қосымша оқу-ғылыми мақсатта жасалған, медициналық кеңес емес.
